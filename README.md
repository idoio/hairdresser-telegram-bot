‍# Telegram-бот для парикмахера / барбера

Бот для автоматизации записи клиентов частного мастера.

## Функции
- Многошаговая форма записи с FSM
- Распознавание возвращающихся клиентов (сохранение имени и телефона)
- Проверка занятости слотов в реальном времени
- Защита от отмены чужих записей (проверка ownership)
- Панель мастера с расписанием на сегодня/завтра
- Выгрузка базы Excel одним кликом
- Автовосстановление Excel-файла при повреждении
- Уведомления мастера о новых записях

## Установка
- Клонируй репозиторий
- Создай .env по примеру .env.example
- Установи зависимости: pip install -r requirements.txt
- Запусти: python bot.py

## Технологии
- Python 3.10+
- Aiogram 3.x
- OpenPyXL
- python-dotenv

## Переменные окружения
- BOT_TOKEN — токен бота от @BotFather
- MASTER_CHAT_ID — Telegram ID мастера (для доступа к панели)
